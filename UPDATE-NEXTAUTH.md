## Cara Update:

1. Buka Vercel Dashboard: https://vercel.com/dashboard
2. Click project "finance-tracker-real"
3. Tab "Settings" (atas)
4. Sidebar kiri → "Environment Variables"
5. Cari "NEXTAUTH_URL"
6. Click icon Edit (pensil)
7. Ganti value dengan URL production lo
8. Save
9. Redeploy (Vercel akan tanya otomatis)

## Atau pakai URL yang lebih pendek:
Cek di Vercel Dashboard → Domains
